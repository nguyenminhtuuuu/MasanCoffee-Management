# Hệ thống Quản lý Cửa hàng Cà phê Masan ☕

Đồ án cuối kỳ môn **Lập trình cơ sở dữ liệu**.

## Giới thiệu đề tài
Hệ thống được thiết kế để số hóa quy trình quản lý tại cửa hàng cà phê Masan, tập trung vào việc quản lý nhân sự, tính lương tự động và kiểm soát kho nguyên liệu chặt chẽ thông qua các kỹ thuật lập trình cơ sở dữ liệu nâng cao.

## Kiến trúc phần mềm (3-Layer Architecture)
Ứng dụng được xây dựng theo mô hình 3 lớp tách biệt để đảm bảo tính dễ bảo trì và mở rộng:
1. **Presentation Layer (Angular)**
2. **Business Logic Layer (C# Services)** 
3. **Data Access Layer (Entity Framework/ADO.NET)**
